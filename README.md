🤖 SO101 Pick and Place Robot
📌 Overview


https://github.com/user-attachments/assets/f1785017-1c5e-4399-b8ef-89bcdc68df12



This project demonstrates an AI-based robotic pick-and-place system using the SO101 robot arm. The system is trained using imitation learning with LeRobot.

🚀 Features
Teleoperation-based data collection
Vision-based learning
Autonomous execution using trained model
🛠️ Tech Stack
Python
LeRobot (Hugging Face)
PyTorch
OpenCV
🎯 Task

Pick objects from one location and place them in another using learned behavior.

📷 Setup
SO101 Leader-Follower configuration
USB camera (top/front view)
🔁 Workflow
Calibration
Teleoperation
Data Recording
Training
Inference


📊 Results
Smooth pick and place execution
Generalization to new positions
🔮 Future Work
Object detection integration
Multi-object handling
Reinforcement learning optimization
